### Build and Deploy the Project
```
mvn clean install
```

This is a Spring Boot project, so you can deploy it by simply using the main class: `Application.java`



### Set up MySQL
```
mysql -u root -p 
> CREATE USER 'tutorialuser'@'localhost' IDENTIFIED BY 'tutorialmy5ql';
> GRANT ALL PRIVILEGES ON *.* TO 'tutorialuser'@'localhost';
> FLUSH PRIVILEGES;
```


### Set up Email

You need to configure the email by providing your own username and password in application.properties
You also need to use your own host, you can use Amazon or Google for example.
You may also setup an email server locally.  See "email.properties.localhost.sample" for more details.

### AuthenticationSuccessHandler configuration for Custom Login Page article
If you want to activate the configuration for the article [Custom Login Page for Returning User](http://www.baeldung.com/custom-login-page-for-returning-user), then you need to comment the @Component("myAuthenticationSuccessHandler") annotation in the MySimpleUrlAuthenticationSuccessHandler and uncomment the same in MyCustomLoginAuthenticationSuccessHandler.

# Gestion Virtuelle d'un Bureau d'Avocat

## 1. Présentation du projet

**Gestion Virtuelle d'un Bureau d'Avocat** est une application web développée dans le cadre d'un projet de fin d'études à la Faculté des Sciences Dhar El Mahraz de Fès.

Ce projet a pour objectif de digitaliser et d'optimiser la gestion des activités d'un bureau d'avocat à travers une plateforme centralisée, sécurisée et accessible aux différents acteurs du bureau.

L'application vise à faciliter la gestion administrative et juridique, à améliorer l'organisation des dossiers et à assurer une meilleure coordination entre les utilisateurs.

## 2. Objectifs du projet

- Digitaliser les activités d'un bureau d'avocat.
- Centraliser les informations relatives aux clients et aux dossiers juridiques.
- Faciliter le suivi et l'organisation des activités professionnelles.
- Assurer la confidentialité et la sécurité des données.
- Gérer les accès selon les rôles et les responsabilités des utilisateurs.
- Améliorer l'efficacité des processus administratifs et juridiques.

## 3. Gestion des utilisateurs

L'application prévoit plusieurs catégories d'utilisateurs :

- **Administrateur :** administration et supervision de la plateforme.
- **Propriétaire du bureau :** gestion globale du bureau.
- **Avocat :** gestion et suivi des dossiers juridiques.
- **Secrétaire :** gestion des tâches administratives.
- **Client :** accès à son espace personnel.

## 4. Technologies utilisées

| Domaine | Technologies |
|---|---|
| Langage de programmation | Java |
| Framework Backend | Spring Boot |
| Sécurité | Spring Security |
| Persistance des données | Spring Data JPA |
| Mapping objet-relationnel | Hibernate |
| Base de données | MySQL |
| Interface utilisateur | Thymeleaf, HTML, CSS, JavaScript |
| Gestion des dépendances | Maven |
| Architecture | MVC (Modèle-Vue-Contrôleur) |

## 5. Architecture de l'application

L'application repose sur une architecture MVC permettant de séparer les différentes responsabilités :

- **Modèle :** gestion des entités et des données.
- **Vue :** présentation des interfaces utilisateur.
- **Contrôleur :** gestion des requêtes et coordination entre les différentes couches de l'application.
